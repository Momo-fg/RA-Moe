This directory stores RegionNet checkpoints generated by:

```bash
python scripts/train_regionnet.py \
  --data-root data/casme2/CASME2_LOSO_with_5channel_region \
  --output-dir checkpoints/regionnet
```

Expected naming format:

```text
regionnet/region_cls_{subject}.pth
```

Example:

```text
regionnet/region_cls_sub01.pth
```
